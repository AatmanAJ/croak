# Security

If you find a way to get scams past Croak, to make it act on the wrong person, or to read data it shouldn't, please email **hello@aatmanjain.com** instead of opening a public issue. Include the steps to reproduce it. You'll get a reply within a few days, and credit in the fix if you'd like it.

Croak stores message text only for open cases, and deletes it after 30 days. See the privacy policy at https://croakbot.base44.app/privacy.
